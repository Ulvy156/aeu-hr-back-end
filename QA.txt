Update existing employee and user dropdowns to use search APIs with debounce.

---

## IMPORTANT RULES (DO NOT BREAK)

* DO NOT create new components
* DO NOT change component structure
* DO NOT refactor unrelated logic
* ONLY replace data source (API call)
* Keep UI exactly the same

---

## Goal

Replace current dropdown data loading with:

* `/api/employees/search?q=`
* `/api/users/search?q=`

Use **debounced search** to avoid too many API calls.

---

## What to change

### 1. Modify existing `<el-select>`

```vue
<el-select
  v-model="value"
  filterable
  remote
  :remote-method="onSearch"
  :loading="loading"
>
```

---

### 2. Add debounce (IMPORTANT)

Use existing project utilities if available (e.g. `useDebounceFn`), otherwise implement a simple debounce.

Example using VueUse:

```ts
import { useDebounceFn } from '@vueuse/core'

const debouncedSearch = useDebounceFn(fetchOptions, 300)
```

---

### 3. Implement search flow

```ts
const loading = ref(false)
const options = ref([])

function onSearch(query: string) {
  debouncedSearch(query)
}

async function fetchOptions(query: string) {
  if (!query || query.length < 2) {
    options.value = []
    return
  }

  loading.value = true

  try {
    const res = await api.get('/api/employees/search', {
      params: { q: query }
    })

    options.value = res.data.map((i: any) => ({
      value: i.employee_id,
      label: i.display
    }))
  } finally {
    loading.value = false
  }
}
```

---

### 4. For user dropdown

Replace API only:

await api.get('/api/users/search', { params: { q: query } })
```

Mapping:

value: i.user_id,

```
